# Python_to_AI_Learning_Journey

Welcome to the Python to AI Learning Journey repository! This collection contains comprehensive Python learning materials and practice assignments covering fundamental concepts through advanced topics.

## 📚 Repository Contents

### 1. **data_science_assignments.ipynb**
NumPy and data science fundamentals
- Creating and manipulating arrays
- Row-wise and column-wise operations:
  - Sum, Min, Max calculations
  - Mean and Standard Deviation
- Random array generation
- Array reshaping and shape operations
- Statistical analysis (median, std, etc.)

### 2. **Exception_handling_exercise.ipynb**
Comprehensive exception handling and error management
- Division by Zero errors
- Invalid input handling
- ValueError and ZeroDivisionError handling
- Try-Except-Else-Finally blocks
- List index out of range errors
- Dictionary KeyError handling
- Custom exceptions for negative numbers and age validation
- Safe file opening and closing
- TypeError handling for incompatible data types
- Finally block for cleanup operations

### 3. **higher_order_function_assignments.ipynb**
Functional programming concepts
- **map()**: Squaring numbers, string to integer conversion, adding list elements
- **filter()**: Selecting even numbers, removing empty strings, filtering by length
- **reduce()**: Sum of numbers, multiplication, finding maximum values
- Lambda functions with multiple operations
- Combining filter and map operations
- Applying normal functions to lists

### 4. **interview_practice_assignments.ipynb**
Common interview questions and problem-solving patterns
- String reversal techniques
- Index-character dictionary creation
- Variable swapping
- Dictionary sorting (by keys and values)
- Vowel and consonant counting
- Anagram detection
- Prime number checking
- Palindrome verification
- Armstrong number validation
- Factorial calculation (iterative and recursive)
- Fibonacci series generation

### 5. **list_comprehension_new.ipynb**
List comprehension techniques and practical applications
- Squares of even numbers
- Removing vowels from strings
- Finding common elements between lists
- Flattening 2D lists
- Finding words starting with specific letters
- Converting string numbers to integers
- Replacing negative numbers with zero
- Extracting digits from strings
- Matrix operations (transposition, flattening)
- Prime number filtering

### 6. **Loop_Control_problems_practice.ipynb**
Loop control structures and iterative programming
- Printing natural numbers (1 to n) using while and for loops
- Reverse number printing (n to 1)
- Printing alphabets (a-z)
- Even and odd number printing (1-100)
- Sum of natural numbers
- Sum of even numbers
- Sum of odd numbers
- Multiplication tables generation

---

## 🎯 Learning Path Recommendation

1. **Beginner**: Start with `Loop_Control_problems_practice.ipynb` to master loop basics
2. **Intermediate**: Progress to `exception_handling_exercise.ipynb` for robust code
3. **Advanced**: Explore `higher_order_function_assignments.ipynb` and `list_comprehension_new.ipynb`
4. **Data Science**: Use `data_science_assignments.ipynb` for NumPy fundamentals
5. **Interview Prep**: Practice `interview_practice_assignments.ipynb` for technical interviews
